# Sample Data

This folder is reserved for sample files and folders used to demonstrate the File Organizer and Duplicate File Finder project.

## Purpose

- Demonstrate file organization by category.
- Test duplicate detection using files with identical content.
- Test how the application handles different file types.

## Safety

Use only test files in this folder. The organizer moves files into category folders, so keep important personal files outside the test data.

**Note:** Sample files can be added here later for project demonstrations and testing.
